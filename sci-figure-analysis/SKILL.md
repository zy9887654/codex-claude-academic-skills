# SCI图表分析方法

用于撰写或审查论文正文中的图表描述与讨论。以源数据、图件和论文研究条件为依据，不把图注当作正文分析的替代品。

## 图文顺序

对每一幅图按以下顺序组织正文：

1. 在正文中首次写出“图N”或“Fig. N”，说明整幅图展示的对象、控制条件、比较维度和指标。
2. 描述数据和可直接观察的关键信息。复合图必须逐一覆盖每个子图 `(a)–(n)`，说明横纵坐标、固定条件、变化方向、峰值、转折、范围、离散度或异常点。
3. 在数据描述之后分析规律。解释变量如何影响过程、不同效应的方向和相对强弱、主导约束及适用边界。
4. 完成上述正文后再放置图件；图注紧随图件。

表格采用同一原则：先在正文出现“表N”，介绍表的内容并描述关键数值，再分析其含义，最后放置表格。

## 数据描述

- 先陈述观察，再作解释。不要在给出数据前直接宣称机制或因果。
- 给出足以支撑结论的定量锚点，例如起点、终点、峰值、转折点、变化量、变化比例、极差和参与样本数。
- 对多条曲线或多组条件，说明共同趋势和有意义的差异，避免逐点复述全部数据。
- 说明统计线、阴影、误差棒、空白区域及颜色编码的含义；报告参与模型数或样本数随条件变化的情况。
- 所有数值必须能在图、表或源数据中核对。数据不足时明确结论边界，并指出需要补充的变量或图表，不得补造结果。

## 规律分析

将“共同作用”展开为可检验的效应链：

- 分别说明每个因素的物理或化学路径及其对目标量的作用方向。
- 讨论竞争效应，而不是把所有因素写成同向作用。例如，同一流量变化可能同时改变热容流率、反应物供给和停留时间。
- 用数量级、比值、变化倍数或理论上限比较各效应的相对强弱，指出哪一项在特定区间占主导。
- 使用其他子图或表格中的证据闭合论证链，例如用转化率解释温度，用停留时间判断动力学补偿是否足够。
- 区分相关性、机理线索和已验证因果。只有现有数据能排除主要替代解释时才使用确定性因果表述。
- 说明结论成立的控制条件和参数范围，避免把局部截面推广为全参数空间规律。

## 复合图写作模板

按内容调整段落数量，不机械套句：

1. `图N展示……，其中(a)……，(b)……，(c)……，(d)……。`
2. 依次描述各子图的主要数据和关键数值。
3. 综合子图证据，分析主导机制、竞争效应、转折原因和参数边界。
4. 插入图N及图注。

## 删除的内容

正文只保留研究内容。删除“补充该图后”“原图不能支持”“前一版表述”“本次修改”等修订过程说明。若需记录修改原因，将其放入审稿回复、修改说明或工作日志。

## 交付前检查

- 正文中的“图N/表N”首次出现早于对应图表。
- 图表放在完整的正文描述和分析之后。
- 每个子图都在正文中被明确描述。
- 关键结论前有可核对的数值或趋势证据。
- 分析说明了效应路径、方向、相对强弱和主导区间。
- 局部规律注明固定条件，统计范围和参与数量明确。
- 正文不含修订过程、版本比较或写作说明。
